# SIH Cognitive Care Platform

An elderly-friendly cognitive care platform developed for Smart India Hackathon 2026.

## IDEA / SOLUTION

- Cognitive Care: Visual-memory games with multilingual voice guidance.
- Caregiver Support: Dashboard to monitor patients and manage personalized care reminders.
- Offline & Alerts: SQLite offline storage with automatic sync and reliable alarm notifications.

## KEY FEATURES

- Visual memory cognitive game
- Cognitive performance tracking
- English, Telugu and Hindi support
- Voice guidance using Flutter TTS
- Caregiver web dashboard
- Medicine and care reminders
- Android alarm with sound and vibration
- Offline SQLite storage
- Automatic data synchronization

## TECHNICAL STACK

- Flutter
- React
- Node.js + Express.js
- SQLite / sqflite
- Flutter TTS
- Android Alarm
- REST APIs

## PRODUCT STATUS

Functional prototype (MVP) with core features implemented and tested end-to-end.
